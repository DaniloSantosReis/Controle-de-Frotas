# 🚗 Sistema de Controle de Frotas

O **Sistema de Controle de Frotas** é uma aplicação web desenvolvida para facilitar a administração e o gerenciamento de frotas de veículos. A plataforma permite cadastrar e gerenciar veículos, motoristas e usuários, organizando as informações em um único ambiente.

O sistema conta com diferentes níveis de acesso (administrador, gerente e motorista), garantindo que cada usuário tenha acesso às funcionalidades correspondentes à sua função. O objetivo é tornar o controle da frota mais prático, organizado e eficiente.

**Tecnologias utilizadas:** PHP, MySQL, HTML5, CSS3, JavaScript e Bootstrap.
